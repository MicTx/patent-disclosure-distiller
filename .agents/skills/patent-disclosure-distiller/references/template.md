# 可复制字段模板：专利技术交底书底稿

> 使用本模板时，把方括号内容替换为材料明确的信息；无法确认的内容保留 `[Q]` 并进入“待补信息”。每个关键句句末只标一个主证据标签（`[F]/[C]/[I]/[A]/[Q]/[L]`）并接来源定位；一个句子同时含事实与推导时先拆成两句再分别标注（见 `methodology.md` 0.2）。本模板全量字段仅适用于 `FULL_DISCLOSURE` 模式；`TARGETED_SECTION`、`REWRITE_AUDIT`、`INTAKE_DRAFT` 只输出用户要求的部分，但仍保留交付说明、证据状态、待补信息和自审摘要。删除不适用字段前，先在交付说明中说明原因。

## 0. 交付说明与证据范围

- **交付模式：** [FULL_DISCLOSURE 完整底稿 / TARGETED_SECTION 指定章节 / REWRITE_AUDIT 现稿改写 / INTAKE_DRAFT 信息采集]
- **技术路线：** [DATA_CONTROL_LOOP / STRUCTURE_PHYSICS / HYBRID]；[I] 一句话说明选择依据和未采用的路线。
- **交付类型：** [技术交底书底稿/改写稿/发明点梳理/待验证方案]
- **主题版本：** [名称、版本、日期]
- **输入材料：** [文件、链接、访谈记录、代码/日志/实验附件]
- **已覆盖范围：** [已处理的技术对象和场景]
- **未覆盖范围：** [缺失的附图、权利要求、实验包、外部检索等]
- **证据状态约定：** 每句一个主标签：`[F]` 材料事实；`[C]` 实际核验；`[I]` 推导；`[A]` 工作假设；`[Q]` 待确认；`[L]` 法律审查。
- **使用边界：** 本稿是技术披露底稿，不构成新颖性、创造性、侵权、公开充分或其他法律结论。[L]
